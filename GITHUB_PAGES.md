# MatheKlar mit GitHub Pages veröffentlichen

Die automatische Veröffentlichung ist bereits eingerichtet.

1. Den gesamten Projektordner als neues GitHub-Repository hochladen.
2. Auf GitHub im Repository **Settings → Pages** öffnen.
3. Unter **Build and deployment** als Quelle **GitHub Actions** auswählen.
4. Den Bereich **Actions** öffnen. Der Ablauf „GitHub Pages veröffentlichen“ startet nach jedem Hochladen auf den Hauptzweig automatisch.

Die Seite erhält anschließend eine Adresse nach diesem Muster:

`https://BENUTZERNAME.github.io/REPOSITORY-NAME/`

Der Ordner `node_modules` wird nicht hochgeladen und ist für GitHub Pages nicht erforderlich.
